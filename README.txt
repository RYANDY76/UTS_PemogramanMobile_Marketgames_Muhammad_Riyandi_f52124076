PC GAMERS MARKET - UTS PEMROGRAMAN MOBILE

Project ini dibuat mengikuti ketentuan soal UTS:
- Custom ListView
- Data game disimpan menggunakan ArrayList
- Desain dibuat kreatif dan menarik
- Ada pencarian, rating, harga, diskon, dan detail produk
- Cover game menggunakan artwork/header game nyata dari Steam CDN dan akan dimuat saat perangkat memiliki internet.

CATATAN PACKAGE:
Saat ini applicationId = com.muhryandy.aplikasi_uts.
Soal UTS meminta format com.nama_stambuk.aplikasi_uts. Sebelum dikumpulkan,
ganti namespace/applicationId dengan nama + stambuk kamu sendiri.

CATATAN BUILD:
Project membutuhkan Android Studio dengan Android Gradle Plugin 8.4.2 dan
Gradle 8.x. Jika Android Studio menawarkan Upgrade Gradle, jangan lakukan
upgrade besar sebelum project berhasil Sync.

CATATAN GAMBAR:
URL cover mengarah ke Steam CDN. Karena gambar dimuat online, perangkat
perlu koneksi internet agar cover tampil.

SUMBER DATA:
GTA V dan RDR2: halaman resmi Rockstar Store.
Forza Horizon 5: halaman resmi Xbox.
Cyberpunk 2077: halaman resmi Cyberpunk.
Harga di aplikasi adalah DATA SIMULASI untuk tampilan marketplace UTS,
bukan klaim harga saat ini.
